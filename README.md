# VoIP

Карта того, что нужно, чтобы в этом репозитории появились голосовые звонки.

Полный разбор слоёв, стека и границ MVP: [ARCHITECTURE.md](./ARCHITECTURE.md).

## Коротко

Звонок работает только если одновременно есть:

- **signaling** — установка и завершение вызова;
- **медиа** — Opus/SRTP (практически всегда через WebRTC);
- **NAT traversal** — STUN + TURN (ICE).

Медиаслой с нуля писать не нужно: на GitHub уже есть Jitsi Meet, LiveKit, Janus, Asterisk, FreeSWITCH, Kamailio, coturn. Каталог и что брать под какую задачу — в [разделе 4 архитектуры](./ARCHITECTURE.md#4-готовые-решения-на-github).

Рабочий дефолт: **LiveKit + свой UI**, а не свой RTP/SIP.

## Статус

Пока нет кода клиентов и серверов — только архитектура. Реализацию начинать после фиксации открытых решений в разделе 10 архитектуры.
